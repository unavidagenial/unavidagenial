# ⚡ Hackers de Procesos | Automatización Inteligente para Negocios

Bienvenido. En este repositorio no entendemos el término **"Hacker"** como el intruso que rompe sistemas, sino en su definición original e inspiradora: **diseñadores de soluciones creativas que desafían los límites de la tecnología para hacer la vida más fácil.**
Entrando a la pagina se recibe con un formulario que verifica que seas humano, a modo de captcha.

en el inicio todo sera iluminado por la linterna del puntero del mouse, en la barra de navegacion se encuentra el encendido y el dom para pasar de modo.

se anuncia el trabajo enfocado a los negocios locales y se busca interaccion con un boton que cambia avatar.

cuenta con menu desplegable y formulario de contacto al finalizar, tambien un pie de pagina interactivo que permite el cambio de color
